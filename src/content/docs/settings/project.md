---
title: Project settings
description: The project's name, warehouse connection and agent configuration.
---

Open **Settings → Project settings**.

| Section | What's there | Who |
|---|---|---|
| **Project name** | Rename the project. | Admins |
| **Connections** | The BigQuery connection shared by Build, Explore, Notebooks and Pipelines, with a **Test connection** button. See [Connect your project](/build/connect/). | Admins edit; others can see the connection exists |
| **Agent** | API keys, model, monthly spend cap and the largest query. See [Set up the agent](/agent/setup/). | Admins |

A project has **one** warehouse connection. If you need another warehouse, create another project.
