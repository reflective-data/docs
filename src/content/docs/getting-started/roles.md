title: Roles
description: "Admin, editor and viewer: what each can do."
---

Everyone has one of three roles, set by an account admin.

| Role | In short |
|---|---|
| **Admin** | Manages the project: connections, the agent's API keys and limits, external dashboards, enabling Explore and Pipelines, people's roles. Can do everything an editor can. |
| **Editor** | Builds things: edits and runs code, creates pipelines, writes documents, uses notebooks and the agent. |
| **Viewer** | Reads things: dashboards, Knowledge, pipeline status, read-only code and notebook results. Can't change or run anything. |

Roles can apply to a whole account, or to a single project only (useful when someone should see just one project).

Account admins change roles under **Settings → Account settings → Team**. They can't add or remove people; ask your Reflective Data account manager for that.

See the full table in [Permissions](/reference/permissions/).
